Neural Multigrid – Machine Learning for Multilevel Solvers

machine-learning numerical-analysis multigrid phd scientific-computing

🧠 Overview

This project corresponds to my PhD research activity, focused on the use of Neural Networks to automatically construct transfer operators for multilevel (multigrid) solvers.

Multigrid methods are among the most efficient solvers for large sparse systems arising from the discretization of partial differential equations (PDEs). However, their effectiveness strongly depends on the quality of the inter-grid transfer operators, which are traditionally handcrafted.

The goal of this project was to learn these operators directly from data, enabling more flexible and potentially more efficient multilevel solvers.

🧪 Methods & Technologies

  • Supervised learning for operator regression
  • Dataset generation from numerical PDE solvers
  • Convolutional and feed-forward neural networks
  • Multilevel numerical methods
  • Scientific visualization of learned operators

Tools & Languages:
Python · TensorFlow · NumPy · SciPy · MATLAB · Scientific Computing

⚙️ My Role

  • Designed the full machine learning pipeline for operator learning
  • Generated large datasets from numerical solvers
  • Trained neural networks for coarse-grid operator approximation
  • Integrated learned operators into multilevel solver frameworks
  • Performed extensive numerical validation and benchmarking
  • Developed visualization tools for learned operators

📈 Outcomes
